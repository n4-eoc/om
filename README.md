# متجر تساهيل — متجر إلكتروني + لوحة تحكم + الدفع عبر تمارا

متجر جوالات مبني بـ **Next.js 14**، ومعه لوحة تحكم لإدارة المنتجات والطلبات، وربط مباشر مع **Tamara API** (التقسيط على 4 دفعات).

المنتجات التسعة (7 جوالات وكفرين) منقولة من متجرك في سلة: الأسماء والأسعار والصور والمواصفات.

---

## المحتويات

| الجزء | المسار |
|---|---|
| الصفحة الرئيسية | `/` |
| صفحة المنتج | `/products/[slug]` |
| السلة | `/cart` |
| إتمام الطلب (التحويل لتمارا) | `/checkout` |
| صفحة نتيجة الدفع | `/checkout/result` |
| لوحة التحكم | `/admin` |
| Webhook تمارا | `/api/tamara/webhook` |

---

## 1) التشغيل على جهازك

المتطلبات: Node.js 20 أو أحدث.

```bash
npm install
cp .env.example .env        # وعبّي القيم (شوف تحت)
npm run db:push             # ينشئ جداول قاعدة البيانات
npm run db:seed             # يضيف المنتجات التسعة
npm run dev                 # افتح http://localhost:3000
```

لوحة التحكم على `http://localhost:3000/admin`، وكلمة المرور هي قيمة `ADMIN_PASSWORD` في ملف `.env`.

> **المخزون:** تم نقله كما هو في سلة، يعني أغلب المنتجات مخزونها 0 وتظهر "نفدت الكمية". حدّث الكميات من **لوحة التحكم ← المنتجات**.

---

## 2) إعداد تمارا

1. تواصل مع فريق التجار في تمارا واطلب **Direct API integration** لموقعك الجديد. الموافقة الحالية مربوطة بمتجر سلة، وللربط المباشر تحتاج مفاتيح خاصة بالموقع.
2. تمارا بتعطيك:
   - **API Token** ← يروح في `TAMARA_API_TOKEN`
   - **Notification Token** ← يروح في `TAMARA_NOTIFICATION_TOKEN`
3. جرّب أول شي على **Sandbox**:
   `TAMARA_API_URL="https://api-sandbox.tamara.co"`
4. بعد ما يشتغل كل شي، انقل للإنتاج:
   `TAMARA_API_URL="https://api.tamara.co"` مع مفاتيح الإنتاج.
5. بعد نشر الموقع على رابط https، سجّل الـWebhook مرة وحدة:
   ```bash
   npm run tamara:webhook
   ```

### كيف يمشي الدفع

```
العميل يضغط "ادفع عبر تمارا"
   ↓  السيرفر يحسب الأسعار من قاعدة البيانات (مو من المتصفح) ويتأكد من المخزون
   ↓  POST /checkout  ← ينشئ جلسة في تمارا
العميل يكمل الدفع في صفحة تمارا
   ↓  تمارا ترسل Webhook (order_approved) + ترجّع العميل لصفحة النتيجة
   ↓  السيرفر يتحقق من الحالة من تمارا مباشرة، ثم:
   ↓  POST /orders/{id}/authorise  ← إلزامي، وإلا تلغي تمارا الطلب
   ↓  الطلب يصير "جاهز للشحن" ويُخصم المخزون (مرة وحدة فقط حتى لو وصل الإشعار أكثر من مرة)
أنت تشحن الطلب من لوحة التحكم
   ↓  POST /payments/capture  ← تحصيل المبلغ من تمارا
```

- **تأكيد الشحن = تحصيل المبلغ.** اضغطه فقط بعد تسليم الشحنة لشركة الشحن.
- **الإلغاء قبل الشحن:** زر "إلغاء الطلب" يلغي الطلب في تمارا ويرجّع المخزون.
- **لو نفدت الكمية** أثناء ما العميل يدفع، الطلب يُلغى تلقائيًا في تمارا وما يُخصم من العميل شي.
- **الاسترجاع بعد الشحن** (Refund) يتم من لوحة تمارا للتجار.

## 3) النشر على الإنترنت (Vercel + Turso)

قاعدة البيانات المحلية ملف، وهذا ما يشتغل على Vercel. استخدم **Turso** (فيها باقة مجانية، ومتوافقة مع الكود بدون أي تعديل):

1. أنشئ قاعدة في [turso.tech](https://turso.tech) وخذ منها:
   - `DATABASE_URL` (يبدأ بـ `libsql://`)
   - `DATABASE_AUTH_TOKEN`
2. على جهازك، حط القيمتين في `.env` وشغّل:
   ```bash
   npm run db:push && npm run db:seed
   ```
3. ارفع المشروع على GitHub واربطه بـ [Vercel](https://vercel.com).
4. في Vercel، أضف كل متغيرات `.env` في **Settings ← Environment Variables**. `NEXT_PUBLIC_SITE_URL` لازم يكون رابط موقعك الفعلي.
5. بعد النشر، شغّل `npm run tamara:webhook` مرة وحدة.

## 4) متغيرات البيئة

| المتغير | الوصف |
|---|---|
| `DATABASE_URL` / `DATABASE_AUTH_TOKEN` | قاعدة البيانات (ملف محلي أو Turso) |
| `NEXT_PUBLIC_SITE_URL` | رابط الموقع، ويُستخدم في روابط الرجوع من تمارا |
| `TAMARA_API_URL` | Sandbox أو Production |
| `TAMARA_API_TOKEN` | مفتاح API من تمارا |
| `TAMARA_NOTIFICATION_TOKEN` | للتحقق من إشعارات تمارا |
| `ADMIN_PASSWORD` | كلمة مرور لوحة التحكم (خلها قوية) |
| `ADMIN_SESSION_SECRET` | نص عشوائي من 32 حرف أو أكثر (`openssl rand -hex 32`) |
| `SHIPPING_FEE_SAR` | رسوم الشحن بالريال (0 = مجاني) |
| `NEXT_PUBLIC_WHATSAPP` | رقم الواتساب بصيغة `9665XXXXXXXX`، ويظهر في الموقع |

## ملاحظات مهمة

- **الضريبة:** الأسعار تُرسل لتمارا على أنها نهائية وضريبتها 0، مثل إعداد منتجاتك في سلة. إذا كنت مسجل في ضريبة القيمة المضافة، عدّل `tax_amount` في `src/lib/orders.ts`.
- **الصور:** حاليًا من سيرفرات سلة. إذا حذفت المنتجات من سلة ممكن تختفي الصور، فالأفضل ترفعها على استضافة ثابتة وتحدّث الروابط من لوحة التحكم.
- **الأمان:** الأسعار والمخزون يُتحقق منها في السيرفر، وإشعارات تمارا يُتحقق من توقيعها (JWT) ثم تُقرأ الحالة من تمارا نفسها، ولوحة التحكم محمية بجلسة موقّعة.
